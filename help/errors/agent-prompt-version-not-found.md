# Agent prompt version not found

`agent_prompt_version_not_found` (HTTP 404). The agent has no version with that number, or you cannot read the agent. Call `list_agent_prompt_versions` for the numbers that exist.

See [Agent prompt history and rollback](../agent-prompt-history.md).
